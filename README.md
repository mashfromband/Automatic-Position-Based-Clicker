# Multi Point Clicker

最大10か所のクリック位置を記憶し、指定した間隔で順番に自動クリックする Windows 向けクリッカーツールです。

## 使い方

```bash
pip install -r requirements.txt
python clicker.py
```

| キー | 動作 |
|------|------|
| F6 | 記憶モード開始（以降の左クリック位置を最大10か所まで記録） |
| F7 | 記憶モード終了（位置を確定） |
| F8 | 自動クリック開始（記憶した位置を順番にループ） |
| F9 | 自動クリック停止 |

- クリック間隔（秒）はウィンドウ上で指定します（最小0.05秒）。
- 記憶した位置は `clicker_settings.json` に保存され、次回起動時も保持されます。新しく記憶モードで1か所以上クリックして F7 で終了したときだけ上書きされます。
- 記憶モード中、このツール自身のウィンドウ上のクリックは記録されません。
- 記憶モード中のクリックは通常どおり他のアプリにも届きます。

## exe 化（任意）

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole clicker.py
```

## 注意

オンラインゲーム等では自動操作が規約で禁止されている場合があります。自己責任で使用してください。
