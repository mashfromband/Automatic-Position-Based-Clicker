# Multi Point Clicker

最大10か所の位置を記憶して順番にクリックする、Rust製のWindowsアプリです。
Pythonや追加のGUIランタイムは必要ありません。日本語/English、ライト/ダークに対応します。

## 起動

デスクトップの **Multi Point Clicker** から起動します。
配布ZIPを使う場合は、展開した **Multi Point Clicker.exe** を開いてください。
Terminalの窓は開きません。再び起動しても、同じアプリのウィンドウを表示します。

起動時にGitHubの最新の安定版を確認し、更新があれば自動で取得してから開きます。
通信できない場合は、手元の版を使います。
新版が起動できない場合は、直前に使えていたアプリと設定の組み合わせへ自動で戻します。
[自動更新と復元の仕組み](docs/automatic-updates.md)も参照してください。

## 使い方

仮想コントローラーをキーボードで操作する場合は、**「キーでクリック」** を開きます。
「ゲーム画面を選ぶ」→「WASDを追加」→各行の「位置を記憶」で、上・左・下・右のボタンを指定し、「キー操作を有効にする」をオンにします。
ゲームを前面にしてキーを押すと、その位置を1回クリックしてマウスを元の位置へ戻します。
押しっぱなしで連打はせず、別のアプリでは通常のキーボード入力になります。
[キーと位置の割り当て方](docs/key-clicks.md)も参照してください。

「動作」で、記憶位置・範囲内の均等クリック・ポインタ位置での連打・ドラッグ中だけの連打を切り替えられます。
追加した3モードの間隔は「連打間隔（秒）」（初期0.001秒）を使います。
`Ctrl+Alt+L` で連打をロックすると、ボタンを離してマウスを動かしながらクリックを続けられます。
停止は全モード共通で、初期値は `Ctrl+Alt+X` です（「設定」で変更できます）。[各動作の指定方法](docs/click-modes.md)も参照してください。

1. 「記憶開始」を押して、クリックしたい位置を順に左クリックします（最大10か所）。アプリ自身へのクリックは記録しません。
2. 「記憶終了」で位置を保存します。何も記録しなかった場合、以前の位置を保持します。
3. 共通のクリック間隔と繰り返し回数を指定し、「自動クリック開始」を押します。
4. 「自動クリック終了」または停止キーで止めます。停止は開始待機中・長いクリック間隔の待機中にも使えます。

クリック間隔の**初期値は0.501秒**、**最小値は0.0000001秒**です。
`0.0000001`、`0.001`、`0.501` のように、小数点以下7桁（100ns単位）まで指定できます。
0秒や小数点以下8桁以上などの無効な値は、エラーを表示して実行しません。
「初期値に戻す」で共通間隔を0.501秒に戻せます。

## クリックごとの間隔

「詳細設定」を開き、「クリックごとに間隔を指定する」を有効にすると、各クリック間の間隔を指定できます。

| 設定行 | 意味 |
| --- | --- |
| 1 → 2 | 1番をクリックしてから2番をクリックするまで |
| 2 → 3 | 2番をクリックしてから3番をクリックするまで |
| 3 → 1（次の周回） | 最後の位置から次の周回の先頭まで |

詳細設定を閉じても個別の設定は有効なままです。
個別指定を無効にすると共通間隔を使い、入力済みの個別の値は保存されます。
位置を削除すると、その位置に対応する間隔も削除されます。
有限周回の最終クリックの後には待機しません。

## その他の設定

- 繰り返し回数: 0 = 無限、最大999999周。
- 開始までの待機: 0〜30秒。
- 左クリック/右クリック、常に手前に表示、日英切替、システム/ライト/ダーク。
- 記憶した位置の個別削除・全削除・画面上の番号プレビュー。
- クリック数・周回数・経過時間を表示します。

| 操作 | 初期のショートカット |
| --- | --- |
| 記憶開始 | Ctrl + Alt + R |
| 記憶終了 | Ctrl + Alt + D |
| 自動クリック開始 | Ctrl + Alt + S |
| 自動クリック終了 | Ctrl + Alt + X |

「設定」で各キーのボタンを押して、組み合わせを変更します（Escで取消）。
ほかのアプリが使用している組み合わせはエラーを表示し、変更前のキーを保持します。

## 保存と旧版からの移行

自動更新する起動方法では、設定を `%LOCALAPPDATA%\MultiPointClicker\data\<識別子>\MultiPointClicker\settings.json` に保存します。
使用中の識別子は `%LOCALAPPDATA%\MultiPointClicker\state.json` の `current.data` に記録します。
初回は従来の `%APPDATA%\MultiPointClicker` の設定とバックアップをコピーし、元のファイルは残します。
`multi-point-clicker.exe` を直接開いた場合は、従来の保存先を使い、自動更新は行いません。
初回のRust版起動時には、旧設定を `settings.python-backup.json` にバックアップし、クリック位置・周回数・ショートカットなどを引き継ぎます。
初回移行時の共通間隔は0.501秒です。以後は保存した間隔を保持します。
以前のRust版のミリ秒設定は100ns単位の整数へ正確に変換し、`settings.v2-backup.json`へ元ファイルを保全します。
壊れた設定ファイルは上書きせず、エラーを表示します。

## ビルドとテスト

WindowsとRust 1.85以上が必要です。

```powershell
cargo build --locked --release
cargo nextest run --locked --workspace
cargo test --locked --workspace --doc
cargo clippy --locked --all-targets -- -D warnings
```

アプリ本体は `target/release/multi-point-clicker.exe`、起動と更新を行う実行ファイルは `target/release/clicker-launcher.exe` に生成されます。
クリックはGUIと独立したスレッドからWindowsのSendInputで送り、待機には高分解能タイマーと最大150µsの最終待機を使います。
記録用マウス監視は位置の記録中だけ動作します。

次の測定モードはGUIの通常操作では使いません。

```powershell
# タイマーだけを測定（マウス入力なし）。結果はJSONファイルへ保存。
.\target\release\multi-point-clicker.exe --benchmark timer-results.json
# 専用の検証ウィンドウへ実際に入力し、件数・位置・間隔・停止を検証。
.\target\release\multi-point-clicker.exe --input-probe input-results.json
```

0.0000001秒は指定可能な最小間隔です。実際の速度はWindowsの負荷、入力監視を行うほかのアプリ、クリック先の処理に左右されます。
対象アプリの処理が毎秒1000回完了することを保証するものではありません。

## 注意

自動操作が利用規約で禁止されているサービスでは使用しないでください。
管理者として動くアプリには、通常権限のプロセスから入力できない場合があります。
