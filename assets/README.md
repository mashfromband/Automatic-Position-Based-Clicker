# アプリアイコン

本人の「アイコン分かりやすいやつを生成して付けといてね。」に従い、画像生成ツールで新規に生成したアイコンです。
白いマウスカーソルと、順番にクリックする3つの位置を表す青いターゲットで構成しています。
`app.png` が生成した元画像、`app.ico` が16/24/32/48/64/128/256pxを収録したWindows用ファイルです。
`windows.rc` と `build.rs` で実行ファイルに埋め込みます。
PNGの元画像は維持し、ICO書き出し時に図形部分を大きく配置して、小さいサイズで余白が目立たないようにしています。

生成時の指示: Multi Point ClickerのWindowsアイコン。白いマウスカーソル、紺の輪郭、線でつながった3つの青いクリック位置。小さい表示でも読める簡単な構図。文字、数字、ロボット、歯車、発光、立体表現を入れず、背景は透明。
