# クリックの動作

「メイン」の「動作」で4種類を切り替えます。
開始は `Ctrl+Alt+S`、停止は全モード共通で `Ctrl+Alt+X` です。
記憶した位置の設定は、ほかの動作へ切り替えても保持します。

| 動作 | 操作 |
| --- | --- |
| 記憶した位置 | 従来どおり、記憶した位置を順番にクリックします。 |
| 範囲内を均等にクリック | 範囲の2隅を指定し、格子状の位置を蛇行して順番にクリックします。 |
| ポインタ位置で連打 | 現在のポインタ位置を連打します。マウスを動かすとクリック先も追従します。 |
| ドラッグ中だけ連打 | 開始後、アプリの外で左ボタンを押して3px以上動かしている間、現在位置を連打します。ボタンを離すと待機します。 |

## 範囲の指定

「範囲を指定（2か所）」を押して、対象の2隅をクリックします。
上下左右を逆に指定しても、同じ長方形として扱います。
`X1 / Y1 / X2 / Y2` へ座標を直接入力する方法も使えます。
`Ctrl+Alt+X` または「記憶終了」で指定を中止でき、以前の範囲と記憶位置は保持します。

「配置間隔 px」は格子の間隔です（初期30、1〜4096px）。
各行を左右交互に巡回し、指定した両端も含めて一巡します。
配置間隔を小さくすると密にクリックします。全位置をメモリへ展開せず、次の1位置だけ計算します。
範囲モードの繰り返し回数は、一巡を1周とします。0は無限です。
自分の操作画面に重なる格子位置はスキップします。画面外やモニターの隙間へ到達したら停止します。

## 連打とロック

追加した3モードは「連打間隔（秒）」を使います。
初期値は0.001秒、入力は最小0.0000001秒・小数点以下7桁までで、実際の速度はOSと対象アプリの処理に依存します。
すべての間隔は100ns単位の整数で保存し、実行時もナノ秒のDurationへ変換します。
記憶位置モードの共通間隔0.501秒と個別間隔は、そのまま別に保存します。
ポインタとドラッグの連打は、以前の繰り返し回数にかかわらず、停止するまで続きます。

「連打ロック」または `Ctrl+Alt+L` は、ドラッグ中の連打をロック/解除します。
停止中に押すと、ドラッグの動作を選んでロック状態で開始します。
ロック中はボタンを離しても、ポインタを動かしながら連打を続けられます。
解除すると物理ドラッグの条件へ戻り、`Ctrl+Alt+X` で全体を停止します。
ロックは保存されず、再起動時と停止後は解除されています。

ポインタ/ドラッグの動作では、クリック入力にマウス移動を含めません。
ドラッグ開始/終了は物理入力だけを監視し、自動で生成したクリックで押下状態が変わらないようにします。
有効なドラッグ中は元の左押下/解放を抑え、対象アプリへ通常のドラッグではなく連続したクリックを送ります。
ドラッグ待機中の短い左クリックは、解放後に1回だけ通常のクリックとして再送します（その間にポインタ位置が変わった場合は、別の位置を誤ってクリックしないよう再送しません）。
押下/解放の検出は待機時も行いますが、連打は3px以上動かした後だけです。
アプリ自身の上では連打しないため、停止や設定の操作ができます。
開始とロック切り替え直後だけは、キーを離してから連打します。その後にShiftやCtrlを保持しても連打は続きます。
ロック切り替え時の解放待ちはCtrl/Altだけが対象で、Shiftは押したまま使えます。
ドラッグモードでは、動かさずに左ボタンを長押ししても解放時の1クリックになります。通常のホールド操作を使う場合は、このモードを停止してください。
ロックキーが他のアプリと競合した場合はボタンだけでロックを操作でき、開始・停止などほかのキーは使えます。

## 確認

範囲の両端/逆順/一画素/負座標/大きな範囲、蛇行順序と一巡、スキップ時の前進、有限周回、ドラッグの押下と移動条件、注入入力の除外、ロックと解除、待機中の停止、旧設定の互換性を、実マウス入力を発生させないテストで確認します。
この変更の受入テストはデスクトップへクリックを送らず、入力先の差し替えと状態遷移で実行します。
非表示の専用ウィンドウに実際のWindowsコントロールを作り、動作の切り替え、座標/配置間隔/連打間隔の入力と保存、既存の個別間隔の保持も確認します。
小数点以下7桁の最小値・上限・丸め誤差なしの保存、旧ミリ秒値の変換とバックアップも検証します。
