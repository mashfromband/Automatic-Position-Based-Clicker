# Windowsの入力言語

Multi Point Clickerの起動中は、Windowsの入力言語切り替えに使われる `Alt+Shift` をアプリ側で予約します。
Altを先に押す場合と、Shiftを先に押す場合の両方を登録します。
クリックを停止している間や、別のアプリが前面にある間も登録を保持します。
アプリを終了すると解除し、Windowsの保存済み言語設定は変更しません。

`Win+Space` やタスクバーからの入力言語の選択は、この登録の対象に含みません。
通常のAlt・Shift入力を作り直したり、仮想キーやマウス入力を追加送信したりはしません。
アプリ内の日本語／Englishの表示切り替えとは別の機能です。

ほかのアプリが同じ組み合わせを予約していて登録できない場合は、画面にエラーを表示し、自動クリックなど既存の機能は引き続き使用できます。
2つ目の登録だけが失敗した場合は、1つ目の登録も解除します。

## 自動クリックの開始キー

Alt単独で自動クリックを開始する初期設定はありません。
「設定」で開始キーを `Alt+Space` などに変更している場合は、その組み合わせで開始します。
現在の開始・停止キーは「設定」で確認・変更できます。

## 検証の範囲

本人の作業画面から切り離した非表示のWindowsデスクトップをテスト用に作り、実際のRegisterHotKey/UnregisterHotKeyを使います。
登録の保持と解除、2つ目の登録が競合した場合の後始末、スレッド終了時の自動解除、既存の開始・停止・ロックキーとの共存を確認します。
テストでは入力先のデスクトップを切り替えず、キーやマウスを送信しません。
入力言語そのものの切り替わりは、このAPIテストだけでは確認していません。
